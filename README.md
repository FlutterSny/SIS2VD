# SIS2VD - Sny's Image Sequence to Video Converter

A VERY user-friendly GUI application for converting image sequences to MP4 videos using FFmpeg. Built with Python and PySide6. Designed for speed: drag the first image of your sequence, click once, and get a shareable MP4.

[![Download](https://img.shields.io/badge/Download-Latest%20Release-blue?style=flat-square)](https://github.com/FlutterSny/SIS2VD/releases)

**Quick Start**: Grab a pre-built binary from the [Releases page](https://github.com/FlutterSny/SIS2VD/releases), run it, and you're done. No Python or pip required — just make sure FFmpeg is installed on your system.

## Features

- **Automatic Sequence Detection**: Detects image sequences from any file in the sequence
- **Gap Detection**: Identifies missing frames in your sequence
- **Drag and Drop**: Simply drag an image file onto the window to load your sequence
- **Real-time Progress**: Watch encoding progress with a progress bar and FFmpeg logs
- **Configurable Quality**: Adjust CRF (quality) and encoding presets
- **Cross-Platform**: Works on Linux and Windows with automatic theme detection
- **Cancellation Support**: Gracefully cancel encoding at any time

## Requirements

- **FFmpeg**: Must be installed and available in your system PATH
  - Linux: `sudo dnf install ffmpeg` (Fedora) or `sudo apt install ffmpeg` (Ubuntu)
  - Windows: Download from [ffmpeg.org](https://ffmpeg.org/download.html) and add to PATH
- **Python 3.11+**: Required only if running from source (see Installation below)

## Installation

### Option 1: Download Pre-built Binary (Recommended)

The easiest way to get started is to download a pre-built executable from the [Releases page](https://github.com/FlutterSny/SIS2VD/releases):

1. Go to [SIS2VD Releases](https://github.com/FlutterSny/SIS2VD/releases)
2. Download the binary for your platform:
   - **Windows**: `SIS2VD.exe`
   - **Linux**: `SIS2VD-linux`
3. Make the Linux binary executable (if needed):
   ```bash
   chmod +x SIS2VD-linux
   ```
4. Run the application

**Note**: FFmpeg is NOT bundled in the executable. Install it separately using the commands in the Requirements section above.

### Option 2: Run from Source

1. Clone the repository:
   ```bash
   git clone https://github.com/FlutterSny/SIS2VD.git
   cd SIS2VD
   ```

2. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Ensure FFmpeg is installed and in your PATH:
   ```bash
   ffmpeg -version
   ```

## Usage

1. **Start the application**:
   - Pre-built binary: double-click `SIS2VD.exe` (Windows) or `./SIS2VD-linux` (Linux)
   - From source: `python run.py`
   > On first launch, a language selection dialog will appear. Choose English or Français to set your preferred UI language.

2. **Load an image sequence**:
   - Click the **Browse** button and select any image from your sequence, OR
   - Drag and drop an image file onto the window

3. **Configure settings**:
   - **Framerate**: Set the output video framerate (default: 30 fps)
   - **CRF (Quality)**: Adjust video quality (0-51, lower = better quality, default: 18)
   - **Preset**: Choose encoding speed vs compression (default: medium)
   - **Output**: Select where to save the MP4 file (auto-generated by default)

4. **Generate video**:
   - Click the **Generate video** button to start encoding
   - Watch progress in the progress bar and log window
   - Click **Cancel** to stop encoding at any time

## Supported Image Formats

PNG, JPG/JPEG, TIFF, EXR, and other formats supported by FFmpeg.

## Sequence Naming

The application automatically detects sequences with various naming patterns:
- `Shot_1_0100.png` → `Shot_1_%04d.png`
- `seq.0001.exr` → `seq.%04d.exr`
- `frame_00123.jpg` → `frame_%05d.jpg`

## Localization

The application supports multiple languages:

- **English** (default)
- **French** (Français)

On first launch, an onboarding dialog prompts you to select your preferred language. You can change this anytime by clicking the **⚙️ Settings** button in the main window and selecting a different language from the dropdown. The application must be restarted for language changes to take effect.

## Known Limitations

- **FFmpeg Required**: FFmpeg must be installed and in PATH — the application cannot function without it
- **Single Sequence**: Only processes one sequence at a time
- **Output Format**: Currently only outputs MP4 format with H.264 codec
- **Gap Handling**: Gaps are detected but not automatically filled
- **Platform Support**: Built and tested on Linux and Windows via CI/CD. macOS support is not currently planned.

## Building from Source

### Compiling Translations

Pre-compiled `.qm` files are included. If you modify translations or add a new language, compile them:

```bash
# Compile all .ts files in locales/
for ts_file in locales/*.ts; do
  pyside6-lrelease "$ts_file" -qm "${ts_file%.ts}.qm"
done
```

To update translation strings from source code:
```bash
pyside6-lupdate src/*.py -ts locales/sis2vd_XX.ts
```

See [locales/locales_README.md](locales/locales_README.md) for detailed workflow documentation.

### CI/CD Pipeline

The project uses GitHub Actions to automatically build binaries on Windows and Linux:

- **Build triggers**: Push to `main` branch, pull requests, or manual dispatch
- **Release triggers**: Git tags matching pattern `v*.*.*` (e.g., `v1.0.0`)
- **Build process**: PyInstaller creates single-file executables (`--onefile`) with assets and locales bundled

See [.github/workflows/build.yml](.github/workflows/build.yml) for the full pipeline configuration.

### Building Locally

To replicate the CI build locally:

```bash
# Install build dependencies
pip install pyinstaller

# Compile translations
for ts_file in locales/*.ts; do pyside6-lrelease "$ts_file" -qm "${ts_file%.ts}.qm"; done

# Build executable (Linux)
pyinstaller --onefile --windowed --name=SIS2VD \
  --add-data="assets:assets" --add-data="locales:locales" run.py

# Build executable (Windows)
pyinstaller --onefile --windowed --icon=assets\icon.ico --name=SIS2VD ^
  --add-data="assets;assets" --add-data="locales;locales" run.py
```

The resulting binary will be in the `dist/` directory.

## Troubleshooting

**"FFmpeg not found" / "FFmpeg non trouvé" error:**
- Ensure FFmpeg is installed and in your system PATH
- Verify by running `ffmpeg -version` in a terminal

**"Pattern not detected" / "Pattern non détecté" error:**
- Ensure the filename ends with a number (e.g., `image_001.png`)
- Check that the file extension is supported

**Encoding fails with "No such file or directory":**
- Verify all sequence files exist in the same directory
- Check that the output directory is writable
